# 🛡️ Women Safety Analytics

> An Android-based women safety and protection system designed with live tracking, alerts, and emergency response features.

## 📱 About the Project

Women Safety Analytics is an Android-based safety application focused on improving personal security through real-time monitoring and emergency assistance.

The project provides safety-oriented features including live tracking, alerts, and emergency response capabilities.

## ✨ Key Features

- 📍 **Live Tracking** — Real-time location tracking for safety monitoring
- 🚨 **Safety Alerts** — Alerts designed to support emergency situations
- 🆘 **Emergency Response** — Features focused on quick response during emergencies
- 📱 **Android Application** — Built as a mobile safety and protection system

## 🎯 Project Objective

The main objective of this project is to provide an Android-based solution that can assist with personal safety through real-time tracking, alerts, and emergency response functionality.

## 🛠️ Technology

- Android
- Gradle

## 📂 Project Structure

This repository contains the Android project files required to build and run the application.
